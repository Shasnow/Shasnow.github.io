StarRailAssistant 提供了一套免费的公开 REST API，用于获取各种数据。无需认证，直接调用即可。

## API 端点

所有 API 的基础地址为：

```
https://starrailassistant.top/api/v1
```

### 获取活动数据

```
GET /activity/{game}.json
GET /activity/{game}-{locale}.json
```

| 参数     | 类型   | 说明                                             |
| -------- | ------ | ------------------------------------------------ |
| `game`   | string | 游戏标识                                         |
| `locale` | string | 可选，语言标签（如 `en-US`）；省略时为默认语言数据 |

#### 响应示例

```json
{
  "version": "4.4",
  "versionName": "鸣笛于归寂之时",
  "startTime": "2026-07-15T06:00:00",
  "endTime": "2026-08-26T06:00:00",
  "cover": "https://...",
  "activities": [
    {
      "name": "反贪「砖」家",
      "description": "世上没有不落灰的角落...",
      "startTime": "2026-07-15T06:00:00",
      "endTime": "2026-08-26T03:59:59",
      "cover": "https://..."
    }
  ]
}
```

#### 响应字段说明

| 字段                       | 类型    | 说明                     |
| -------------------------- | ------- | ------------------------ |
| `version`                  | string  | 当前游戏版本号           |
| `versionName`              | string  | 版本名称                 |
| `startTime`                | string  | 版本开始时间（ISO 8601） |
| `endTime`                  | string  | 版本结束时间（ISO 8601） |
| `cover?`                   | string? | 版本封面图 URL           |
| `activities`               | array   | 活动列表                 |
| `activities[].name`        | string  | 活动名称                 |
| `activities[].description` | string  | 活动描述                 |
| `activities[].startTime`   | string  | 活动开始时间（ISO 8601） |
| `activities[].endTime`     | string  | 活动结束时间（ISO 8601） |
| `activities[].cover?`      | string? | 活动封面图 URL           |

## 贡献指南

我们欢迎社区贡献活动数据！如果你想为更多游戏提供支持或发现活动信息有误或缺失，可以通过以下方式参与贡献。

### 新增游戏支持

1. **Fork 仓库**：访问 [StarRailAssistant 文档站仓库](https://github.com/Shasnow/Shasnow.github.io) 并 Fork
2. **新增游戏支持**：在 `src/data/games.ts` 中新增游戏条目，填写游戏标识、名称、语言列表、数据源地址等。
3. **提交 PR**：创建 Pull Request 并说明新增游戏支持。

按照上面的步骤新增游戏支持后，一段时间后，游戏数据将自动更新。

#### 游戏支持格式

添加新的游戏支持/更新游戏支持时，请按照以下格式：

```json
{
  "id": "游戏标识", // 游戏标识，如 "sr"
  "name": "可读游戏名称",
  "locales": [
    "zh-CN", // 支持的语言列表
    "en-US" // 其他语言名称
  ],
  "defaultLocale": "zh-CN", // 默认语言，默认语言在生成文件时将省略语言标签后缀
  "dataSource": "数据源" // 游戏活动数据的原始来源，此字段主要面向AI，告诉AI将如何获取游戏数据。
}
```

### 维护活动数据

以下方式适用于简单的内容修改（如修正个别活动时间、名称或描述、添加活动封面图等）：

1. **Fork 仓库**：访问 [StarRailAssistant 文档站仓库](https://github.com/Shasnow/Shasnow.github.io) 并 Fork
2. **修改数据**：编辑 `public/api/v1/activity/` 目录下对应的 JSON 文件。默认语言数据位于 `/{game}.json`（中文）；其他语言的数据位于 `/{game}-{locale}.json`（如 `sr-en-US.json`）。
3. **提交 PR**：创建 Pull Request 并说明修改内容

#### 活动数据格式

添加新的游戏数据/更新活动数据时，请按照以下格式：

```json
{
  "version": "当前游戏版本号",
  "versionName": "当前游戏版本名称",
  "startTime": "2026-07-15T06:00:00", // 版本开始时间
  "endTime": "2026-08-26T06:00:00", // 版本结束时间
  "cover": "https://...", // 版本封面图 URL
  "activities": [
    {
      "name": "活动名称",
      "description": "活动描述",
      "startTime": "2026-07-15T06:00:00", // 活动开始时间
      "endTime": "2026-08-26T03:59:59", // 活动结束时间
      "cover": "https://..." // 活动封面图 URL
    }
    // 其他活动...
  ]
}
```

:::tip

- 时间请使用 ISO 8601 格式（`YYYY-MM-DDTHH:mm:ss`）
- `cover` 字段可选，如无封面图可留空字符串 `""`
- 版本信息（`version`、`versionName`）需要同步更新
- 其他语言的数据写入 `{game}-{locale}.json`（如 `sr-en-US.json`），命名与默认语言文件保持同一结构

:::

:::note[注意事项]

- 活动时间请确保准确，建议参考官方公告
- 仅写入有确切来源的时间，无法核实的活动请留空或不收录
- 提交 PR 前请检查 JSON 格式是否正确
- 如有疑问，可以在 [GitHub Issues](https://github.com/Shasnow/Shasnow.github.io/issues) 中讨论

:::
