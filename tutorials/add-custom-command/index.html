添加自定义命令

在 SRA 中添加自定义命令

Section titled “在 SRA 中添加自定义命令”

工作原理

Section titled “工作原理”

SRA 的命令系统基于 Python 的 cmd2 库，通过一套“动态发现 + 自动注册”的机制加载命令：

  1. 动态导入：SRACore/__main__.py 在启动时调用 dynamic_import("tasks")，扫描 tasks/ 目录下所有 .py 文件并逐一 importlib.import_module。这一步确保 tasks/ 中的所有模块都被加载到内存。

  2. 命令集（CommandSet）：cmd2 提供了 CommandSet 基类。任何继承自 cmd2.CommandSet[SRACli] 的类，其内部以 do_ 开头的方法会被 cmd2 自动识别为命令。你还可以使用 @cmd2.with_argparser 装饰器为命令添加参数解析，用 @cmd2.as_subcommand_to 创建子命令组。

  3. 自动注册：SRACli 初始化时设置了 auto_load_commands=True。cmd2 会在所有已导入的模块中搜索 CommandSet 的子类，自动实例化并注册它们——无需手动调用任何注册函数。

简单来说：把文件放进 tasks/ 目录，写一个 CommandSet 子类，SRA 启动时就会自动发现并注册你的命令。

先决条件

Section titled “先决条件”
  • 已安装 SRA 或已获取 SRA 源码
  • 了解 Python 编程基础
  • 文本编辑器（如 VSCode、Notepad++）
